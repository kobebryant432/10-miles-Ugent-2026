# Ugent Measurement campaign at Antwerp 10 Miles (2026)

A repo to host a mini website for the measurement campaign at the Antwerp 10 Miles in 2026. 
The QR code will be printed on the participants' bibs, which will link to this [website](https://kobebryant432.github.io/10-miles-Ugent-2026/).
